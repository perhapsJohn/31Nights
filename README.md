# 31 Nights (web build)

The browser build of **31 Nights**, a Halloween daily puzzle: one door on
Trick-or-Treat Street opens every October night, four quick rounds, double
points on Halloween. Served by GitHub Pages at https://perhapsjohn.github.io/31Nights/
and played in the Scareathon arcade.

This repo holds only the exported files (Godot 4.6 web export); the game's
source lives elsewhere and publishes here with `tools/publish_web.sh`.
